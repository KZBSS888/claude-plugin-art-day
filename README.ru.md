# Art Day для Claude

English version: [README.md](README.md).

Одна музейная картина каждый день прямо в Claude: репродукция, короткая история на языке вашей системы, деталь, к которой стоит присмотреться, оценки от 1 до 5 и избранное. Следующие картины подбираются с учётом ваших оценок, но всегда остаётся место новому.

Установка в Claude Code одной командой:

```
/plugin install art-day --marketplace KZBSS888/claude-plugin-art-day
```

Затем напишите в чат `art day`.

Источник один — Wikimedia Commons. Показываются только репродукции с правами Public Domain или CC0.

## Как это работает

1. Вы пишете «art day» (или «покажи картину дня») — открывается карточка.
2. Если на текущий музейный день (он начинается в 09:00 по Парижу) картины ещё нет, Claude ищет свежих кандидатов в Commons, плагин случайно выбирает одного с весами по вашему вкусу, Claude рассматривает репродукцию и пишет текст.
3. Автора, год, музей, ссылку и права плагин берёт сам из Wikimedia, а не из текста модели.
4. Показанные картины не повторяются. В день — не больше трёх попыток подбора.
5. После публикации Claude обновляет закреплённую карточку: инструмент `art_day_card` собирает страницу, репродукцию и миниатюры избранного в папке данных, Claude публикует их своим инструментом Artifact по сохранённому адресу. Страница закреплена в боковой панели Claude, открывается без обращения к Wikimedia и устроена так же, как карточка в чате: вкладки «Сегодня», «Избранное» и «Мой вкус», сердечко, просмотр репродукции (шаблон — `server/card.html`). Звёзды, избранное и признаки на ней сохраняются в базе артефакта, а при следующем «art day» Claude переносит их в коллекцию плагина; там, где приложение Claude открывает страницам локальные серверы, оценка уходит в плагин сразу (имя сервера задаётся переменной `ART_DAY_HOST_SERVER`, по умолчанию `host:plugin_art-day_art-day`). В браузере без этих возможностей нажатие копирует сообщение для чата.

## Как оценки становятся вкусом

Оценка 1–5 и избранное дают вес всем тегам картины и её автору; при подборе случайный выбор умножает шансы кандидатов на эти веса, и ни одна работа не выпадает совсем. Теги хранятся по группам: цвета, настроение, сюжет, манера. Признаки под оценкой усиливают именно свою группу: «Цвета» — цветовые теги картины, «Настроение» — теги настроения, «Сюжет» — сюжетные, «Манера художника» — теги манеры и самого автора. «История картины» на подбор не влияет и остаётся заметкой для вас. Оценивать можно тремя способами с одним результатом: словами в чате, в карточке чата и на закреплённой странице.

Плагин ничего не запускает сам. Чтобы картина менялась без вашего участия, создайте в Claude задачу по расписанию с текстом «Подбери картину дня».

## Два способа подключения

Код один, вы выбираете, где он работает. Возможности различаются из-за правил самого Claude.

| | На своём компьютере | На своём сервере |
|---|---|---|
| Установка | плагин или файл `.mcpb` | коннектор по адресу сервера |
| Где хранятся оценки | на компьютере | на сервере |
| Карточка в чате | да | да |
| Оценки щелчком по звёздам | через сообщение в чат | напрямую |
| Закрепление в боковой панели Claude | да, артефактом Claude (обновляет Claude после публикации) | да, артефактом Claude или встроенным закреплением коннектора |
| Работает в обычном чате Claude Desktop | только `.mcpb` | да |

### На своём компьютере

Нужен Node.js 20 или новее.

- **Плагин** (Cowork и Claude Code): Customize → Plugins → Add → добавьте этот репозиторий или загрузите его архивом.
- **Расширение** (чат Claude Desktop): упакуйте папку командой `mcpb pack` (инструмент `@anthropic-ai/mcpb`) и установите полученный файл через Settings → Extensions.

Коллекция хранится в папке данных плагина, а для расширения — в `~/.art-day`.

### На своём сервере

```
ART_DAY_TOKEN=<случайная строка от 32 символов> node server/http.mjs
```

Сервер слушает `127.0.0.1:8787`. Поставьте перед ним HTTPS (обратный прокси или туннель) и добавьте в Claude коннектор с адресом `https://ваш-адрес/mcp/<ART_DAY_TOKEN>`. Адрес содержит ключ доступа: не публикуйте его. Параметры: `ART_DAY_HOST`, `ART_DAY_PORT`, `ART_DAY_DATA` (папка с коллекцией).

## Что плагин запускает, получает и отправляет

- **Запускает** только собственный код на Node.js из папки `server/`. Сторонних пакетов нет, установка ничего не скачивает. На macOS дополнительно выполняет одну системную команду `defaults read -g AppleLanguages`, чтобы узнать язык системы.
- **Обращается** к трём адресам Wikimedia: `commons.wikimedia.org` (поиск и лицензии), `www.wikidata.org` (автор, год, музей), `upload.wikimedia.org` и `thumb.wikimedia.org` (репродукции). В запросах передаются слова поиска и идентификаторы работ. Оценки, избранное и профиль вкуса никуда не отправляются. Wikimedia просит указывать контакт в User-Agent: задайте переменную `ART_DAY_CONTACT` (адрес репозитория или почта), иначе действует лимит 10 запросов в минуту.
- **Карточка** загружает репродукцию напрямую с серверов изображений Wikimedia, поэтому Wikimedia видит ваш IP-адрес, как при обычном просмотре страницы.
- **Хранит** на вашем устройстве `collection.json` и `ART-TASTE.md`: полные карточки текущей работы и избранного, краткую историю показов, оценки, адрес закреплённого артефакта. В папке `card/` лежат страница, репродукция текущей картины и миниатюры избранного для артефакта.
- **Не делает**: не читает другие файлы, не использует учётные записи и ключи, не собирает статистику, не меняет настройки Claude.

Подбор картины выполняет Claude, поэтому расходует лимиты вашей подписки. Тексты пишет языковая модель: факты о картине стоит перепроверять по ссылке на источник в карточке.

## Разработка

После правок кода сервера начните новую сессию Claude Code: `/reload-plugins` перечитывает навык и манифест, но уже запущенный процесс сервера плагина не перезапускает.

`npm test` — проверки без сети. `npm run live -- "monet"` — пробный поиск в настоящем Commons, ничего не сохраняет. Устройство: `server/store.mjs` (коллекция и вкус), `server/commons.mjs` (поиск и проверка прав), `server/pick.mjs` (случайный выбор), `server/tools.mjs` (инструменты), `server/card.mjs` (страница закреплённого артефакта), `server/mcp.mjs` (протокол), `server/view.html` (карточка).

Лицензия MIT распространяется на код. Репродукции и музейные данные сохраняют собственные права и принадлежат своим источникам.

## Язык

Плагин говорит на языке, установленном в системе, а не на одном зашитом. Его определяет `server/i18n.mjs`: на macOS это первый язык из списка системы, на Linux — `LC_ALL`/`LC_MESSAGES`/`LANG`, на Windows — язык системы, который видит Node; переменная `ART_DAY_LANG` задаёт язык явно.

- Название, историю и «Присмотритесь» Claude каждый день пишет на этом языке; имена автора и музея сервер берёт из Wikidata на нём же, а если их там нет — на английском.
- Постоянные тексты карточек (кнопки, подписи, названия инструментов) берутся из словаря. Английский и русский встроены; для любого другого языка Claude один раз переводит английский словарь и передаёт его через `art_day_language`, перевод хранится в коллекции.
- Выбрать другой язык можно фразой в чате («art day на русском»): `art_day_language` запоминает выбор, `auto` возвращает язык системы.
- Описания инструментов и ответы сервера предназначены модели и написаны по-английски. Описания плагина в `plugin.json` и `manifest.json` статичны и тоже английские.
- Признаки оценки хранятся ключами (`colors`, `mood`, `subject`, `manner`, `story`); прежние русские названия в старой коллекции переводятся в ключи при загрузке.
